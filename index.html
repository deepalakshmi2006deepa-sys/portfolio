Major Engineering Project Dossier

An Intelligent IoT-Driven Smart Farming Using Digital Twin for Groundnut Disease Prediction and Blockchain for Data Transparency

1. Problem Statement

Groundnut (Arachis hypogaea) is a vital commercial and oilseed crop cultivated globally. However, farm yields are severely impacted by unforeseen fungal and foliar leaf diseases (such as Early Leaf Spot, Late Leaf Spot, and Rust), coupled with volatile soil moisture and micro-climate fluctuations. Traditional farming relies on manual visual leaf inspection, which is often late, prone to subjective error, and lacks real-time environmental context. Additionally, centralized farm advisory systems lack auditability, making sensor readings and predictive logs susceptible to tampering or unreliable record management.

2. Project Objective

  • To design an automated, IoT-enabled groundnut agricultural monitoring system using microcontroller telemetry.
  • To implement machine learning and deep learning models to accurately classify groundnut foliar leaf diseases from image specimens.
  • To engineer a virtual Digital Twin representing physical farm sensor metrics, leaf disease states, and plant health indicators in real time.
  • To enforce data transparency and record integrity using Blockchain concepts, preventing unauthorized alteration of diagnostic logs and sensor histories.
  • To build a unified web dashboard presenting real-time telemetry, model diagnostics, and immutable historical records for farm decision-makers.

3. Proposed Solution

The proposed solution is a cohesive 4-tier cyber-physical architecture:

Tier 1

IoT Edge Layer

ESP32 microcontroller nodes deployed in the field stream soil moisture, ambient temperature, and relative humidity.

Tier 2

AI / ML Diagnostic Layer

Computer vision and machine learning pipelines process uploaded groundnut leaf imagery to classify fungal/pathogenic diseases.

Tier 3

Digital Twin Layer

A virtual counterpart synchronizes edge telemetry and ML diagnosis, simulating crop vigor and risk conditions in real time.

Tier 4

Blockchain Audit Layer

Hashes of sensor readings, timestamps, and model predictions are sealed into cryptographic blocks for tamper-proof transparency.

4. System Architecture & Workflow

The system operates in a sequential, automated data pipeline:

IoT Sensor Data + Leaf Image
Data Preprocessing & Normalization
AI/ML Disease Prediction
Digital Twin Simulation
Blockchain Record Storage
Farm Dashboard & Reports
